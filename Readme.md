# DMorse — Morse Code Encoder and Decoder

Python-based Morse code tool for CTFs, learning, and quick signal translation.

## Features

- Decode Morse code into readable text
- Encode plain text into Morse code
- Save decoded output to a file
- Supports letters, numbers, and common punctuation

---

## How to Get DMorse

### Method 1: Download and Run

1. Download the `Dmorse.py` file from the repository.
2. Open a terminal in the project folder.
3. Run:

```bash
python Dmorse.py
```

or:

```bash
python3 Dmorse.py
```

### Method 2: Copy the Code Manually

1. Copy the full `Dmorse.py` code.
2. Paste it into a new file and save it as `Dmorse.py`.
3. Run:

```bash
python Dmorse.py
```
