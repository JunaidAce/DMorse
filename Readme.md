#  DMorse — Decodes Morse Code

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)

> Python-based Morse Code encoder & decoder for CTFs and signal translation.

**⭐ How to get Dmorse**

**🔹 Method 1 — Download & Run**

1. Download the DMorse.py file from the repository.

2. Run the tool:
   
**python dmorse.py OR python3 dmorse.py**

**🔹 Method 2 — Copy Code Manually**

1. Copy the full DMorse.py code.
2. Paste it into a new file and save it as:

  **dmorse.py**

3. Run it:
**python dmorse.py**
